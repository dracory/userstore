Getting Started

UserStore is a robust user management package for Go. It supports SQLite, MySQL, and PostgreSQL through a standard *sql.DB connection.

Installation

go get github.com/dracory/userstore

Creating the Store

Create a store with NewStore and a NewStoreOptions struct:

userStore, err := userstore.NewStore(userstore.NewStoreOptions{
    DB:                 databaseInstance, // *sql.DB
    UserTableName:      "user",
    RoleTableName:      "role",       // required when RolesEnabled is true
    UserRoleTableName:  "user_role",  // required when RolesEnabled is true
    RolesEnabled:       true,
    GroupTableName:     "groups",     // required when GroupsEnabled is true ("group" is a reserved SQL keyword)
    UserGroupTableName: "user_group", // required when GroupsEnabled is true
    GroupsEnabled:      true,
    AutomigrateEnabled: true,
    DebugEnabled:       false,
})

if err != nil {
    return err
}

Store Options

OptionTypeDescription
DB*sql.DBDatabase connection (required).
UserTableNamestringName of the user table (required).
RolesEnabledboolEnable role and user-role tables.
RoleTableNamestringRequired when RolesEnabled is true.
UserRoleTableNamestringRequired when RolesEnabled is true.
GroupsEnabledboolEnable group and user-group tables.
GroupTableNamestringRequired when GroupsEnabled is true. Avoid "group" — it is a reserved SQL keyword.
UserGroupTableNamestringRequired when GroupsEnabled is true.
AutomigrateEnabledboolRun MigrateUp automatically on store creation.
DebugEnabledboolEnable debug output.

API Conventions

All entities use the same convention:

  • Getters use the Get prefix: GetID(), GetName(), GetEmail(), GetStatus().
  • Setters use the Set prefix and return the entity for chaining: SetName("John").SetStatus(userstore.USER_STATUS_ACTIVE).
  • Entities are created with constructors: NewUser(), NewRole(), NewGroup(), NewUserRole(), NewUserGroup().
  • Queries are created with: NewUserQuery(), NewRoleQuery(), NewGroupQuery(), NewUserRoleQuery(), NewUserGroupQuery().
  • All store methods take a context.Context as the first argument.

Quick Example

user := userstore.NewUser().
    SetStatus(userstore.USER_STATUS_ACTIVE).
    SetFirstName("John").
    SetLastName("Doe").
    SetEmail("test@test.com")

err := userStore.UserCreate(context.Background(), user)

Runnable Examples

The examples/ directory contains complete runnable programs:

  • examples/basic — creating, finding, updating, and soft deleting users
  • examples/roles — creating roles and assigning them to users
  • examples/groups — creating groups and managing memberships
go run ./examples/basic
