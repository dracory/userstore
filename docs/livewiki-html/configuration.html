Configuration

Configuration options and environment variables for UserStore

Store Configuration

UserStore is configured through the NewStoreOptions struct when creating a new store instance.

NewStoreOptions Structure

type NewStoreOptions struct {
    UserTableName      string
    DB                 *sql.DB
    DbDriverName       string
    AutomigrateEnabled bool
    DebugEnabled       bool
}

Configuration Options

Option Type Required Default Description
UserTableName string Yes None Name of the user table in the database
DB *sql.DB Yes None Database connection instance
DbDriverName string No Auto-detected Database driver name (sqlite, mysql, postgres)
AutomigrateEnabled bool No false Automatically create tables on initialization
DebugEnabled bool No false Enable debug logging for SQL queries

Configuration Examples

Basic Configuration

userStore, err := userstore.NewStore(userstore.NewStoreOptions{
    DB:                 databaseInstance,
    UserTableName:      "user",
    AutomigrateEnabled: true,
    DebugEnabled:       false,
})

Configuration with Custom Table Name

userStore, err := userstore.NewStore(userstore.NewStoreOptions{
    DB:                 databaseInstance,
    UserTableName:      "app_users",
    AutomigrateEnabled: true,
    DebugEnabled:       false,
})

Configuration with Debug Mode

userStore, err := userstore.NewStore(userstore.NewStoreOptions{
    DB:                 databaseInstance,
    UserTableName:      "user",
    AutomigrateEnabled: true,
    DebugEnabled:       true,
})

Configuration without Auto-Migration

userStore, err := userstore.NewStore(userstore.NewStoreOptions{
    DB:                 databaseInstance,
    UserTableName:      "user",
    AutomigrateEnabled: false,
    DebugEnabled:       false,
})

// Manually run migration
err = userStore.MigrateUp(context.Background())

Database Configuration

UserStore requires a valid *sql.DB connection. Here are examples for different databases:

SQLite Configuration

import (
    "database/sql"
    _ "modernc.org/sqlite"
)

db, err := sql.Open("sqlite", "./userstore.db")
if err != nil {
    log.Fatal(err)
}
defer db.Close()

// Configure connection pool
db.SetMaxOpenConns(1) // SQLite requires single connection
db.SetMaxIdleConns(1)

MySQL Configuration

import (
    "database/sql"
    _ "github.com/go-sql-driver/mysql"
)

db, err := sql.Open("mysql", "user:password@tcp(localhost:3306)/dbname?parseTime=true")
if err != nil {
    log.Fatal(err)
}
defer db.Close()

// Configure connection pool
db.SetMaxOpenConns(25)
db.SetMaxIdleConns(5)
db.SetConnMaxLifetime(5 * time.Minute)

PostgreSQL Configuration

import (
    "database/sql"
    _ "github.com/lib/pq"
)

db, err := sql.Open("postgres", "postgres://user:password@localhost:5432/dbname?sslmode=disable")
if err != nil {
    log.Fatal(err)
}
defer db.Close()

// Configure connection pool
db.SetMaxOpenConns(25)
db.SetMaxIdleConns(5)
db.SetConnMaxLifetime(5 * time.Minute)

Table Name Configuration

The table name can be changed dynamically after store creation:

// Set table name
userStore.SetUserTableName("custom_users")

// Get current table name
tableName := userStore.GetUserTableName()

Debug Configuration

Debug mode can be toggled at runtime:

// Enable debug mode
userStore.EnableDebug(true)

// Disable debug mode
userStore.EnableDebug(false)

Migration Configuration

Migrations can be run manually with transaction support:

// Run migration with transaction
tx, err := db.Begin()
if err != nil {
    return err
}

err = userStore.MigrateUp(context.Background(), tx)
if err != nil {
    tx.Rollback()
    return err
}

err = tx.Commit()
if err != nil {
    return err
}

Environment Variables

UserStore does not directly use environment variables, but you can use them to configure your database connection:

Example with Environment Variables

import (
    "os"
    "database/sql"
    _ "github.com/lib/pq"
)

dbHost := os.Getenv("DB_HOST")
dbPort := os.Getenv("DB_PORT")
dbUser := os.Getenv("DB_USER")
dbPass := os.Getenv("DB_PASSWORD")
dbName := os.Getenv("DB_NAME")

connStr := fmt.Sprintf("postgres://%s:%s@%s:%s/%s?sslmode=disable",
    dbUser, dbPass, dbHost, dbPort, dbName)

db, err := sql.Open("postgres", connStr)
if err != nil {
    log.Fatal(err)
}

Best Practices

Configuration Best Practices
  • Use AutomigrateEnabled: true in development for convenience
  • Use AutomigrateEnabled: false in production and run migrations manually
  • Enable debug mode only during development
  • Configure connection pool settings based on your database type
  • Use environment variables for sensitive configuration (passwords, etc.)
  • Always close database connections when done
  • Use transactions for migration in production

Common Issues

Table Already Exists

If AutomigrateEnabled: true and the table already exists, the migration will fail. Use AutomigrateEnabled: false or handle the error gracefully.

Driver Not Detected

If the driver is not auto-detected, specify it explicitly:

userStore, err := userstore.NewStore(userstore.NewStoreOptions{
    DB:                 databaseInstance,
    UserTableName:      "user",
    DbDriverName:       "mysql",
    AutomigrateEnabled: true,
})

Connection Pool Exhaustion

Configure appropriate connection pool settings to avoid connection exhaustion:

db.SetMaxOpenConns(25)
db.SetMaxIdleConns(5)
db.SetConnMaxLifetime(5 * time.Minute)
