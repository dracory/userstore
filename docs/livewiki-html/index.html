UserStore

A robust user management package for Go applications

UserStore provides comprehensive user and role management with support for multiple database backends, soft deletes, metadata storage, password hashing, and a fluent method-chaining API.

Learn More Get Started
Multi-Database Support

Supports SQLite, MySQL, and PostgreSQL out of the box.

Security

Built-in password hashing with bcrypt and secure authentication.

Fluent API

Method chaining for intuitive and readable code.

Query Builder

Powerful query builder for complex user searches.

Quick Start

userStore, err := userstore.NewStore(userstore.NewStoreOptions{
    DB:                 databaseInstance,
    UserTableName:      "user",
    AutomigrateEnabled: true,
    DebugEnabled:       false,
})

Key Features

  • User and Role management
  • Soft delete support
  • Metadata storage for custom fields
  • Password hashing and verification
  • Method chaining for fluent API
  • Transaction support
  • Query builder for complex searches
