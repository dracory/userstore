Getting Started

Setup, installation, and quick start guide for UserStore

Prerequisites

Before you begin, ensure you have the following:

  • Go 1.26 or higher installed
  • A supported database (SQLite, MySQL, or PostgreSQL)
  • Basic knowledge of Go programming

Installation

Install UserStore using Go modules:

go get github.com/dracory/userstore

Quick Start

Step 1: Initialize the Store

Create a new UserStore instance with your database connection:

userStore, err := userstore.NewStore(userstore.NewStoreOptions{
    DB:                 databaseInstance,
    UserTableName:      "user",
    AutomigrateEnabled: true,
    DebugEnabled:       false,
})

if err != nil {
    return errors.Join(errors.New("userstore.NewStore"), err)
}

Step 2: Create a User

Create a new user with method chaining:

user := userstore.NewUser().
    SetStatus(userstore.USER_STATUS_ACTIVE).
    SetFirstName("John").
    SetLastName("Doe").
    SetEmail("test@test.com")

err := userStore.UserCreate(context.Background(), user)

if err != nil {
    return errors.New("user failed to create")
}

Step 3: Find a User

Find a user by ID:

user, err := userStore.UserFindByID(context.Background(), userID)

Step 4: List Users

List users with a query builder:

query := userstore.NewUserQuery().
    SetStatus(userstore.USER_STATUS_ACTIVE).
    SetLimit(10)

users, err := userStore.UserList(context.Background(), query)

Step 5: Update a User

Update user properties:

user.SetFirstName("Jane")
user.SetEmail("jane@example.com")

err := userStore.UserUpdate(context.Background(), user)

Step 6: Soft Delete a User

Soft delete a user (preserves data):

err := userStore.UserSoftDelete(context.Background(), user)

Database Setup

SQLite

import (
    "database/sql"
    _ "modernc.org/sqlite"
)

db, err := sql.Open("sqlite", "./userstore.db")
if err != nil {
    log.Fatal(err)
}
defer db.Close()

MySQL

import (
    "database/sql"
    _ "github.com/go-sql-driver/mysql"
)

db, err := sql.Open("mysql", "user:password@/dbname")
if err != nil {
    log.Fatal(err)
}
defer db.Close()

PostgreSQL

import (
    "database/sql"
    _ "github.com/lib/pq"
)

db, err := sql.Open("postgres", "postgres://user:password@localhost/dbname?sslmode=disable")
if err != nil {
    log.Fatal(err)
}
defer db.Close()

Configuration Options

Option Type Required Description
UserTableName string Yes Name of the user table in the database
DB *sql.DB Yes Database connection instance
DbDriverName string No Database driver name (auto-detected if not provided)
AutomigrateEnabled bool No Automatically create tables on initialization
DebugEnabled bool No Enable debug logging

Common Patterns

Password Hashing

Always hash passwords before storing:

user := userstore.NewUser()
err := user.SetPasswordAndHash("securePassword123")
if err != nil {
    return err
}

Password Verification

Verify passwords during authentication:

if user.PasswordCompare(inputPassword) {
    // Password is correct
} else {
    // Password is incorrect
}

Working with Metadata

Store custom fields using metadata:

// Set metadata
err := user.SetMeta("customField", "customValue")

// Get metadata
value := user.GetMeta("customField")

// Set multiple metas
err := user.SetMetas(map[string]string{
    "field1": "value1",
    "field2": "value2",
})

User Status Checks

Check user status with helper methods:

if user.IsActive() {
    // User is active
}

if user.IsSoftDeleted() {
    // User has been soft deleted
}

if user.IsAdministrator() {
    // User has administrator role
}
