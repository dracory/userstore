User Module

User entity implementation

Overview

The User module implements the user entity with all properties, methods, and business logic. It extends the dataobject.DataObject base class and implements the UserInterface.

Key Files

  • user_implementation.go - User entity implementation
  • interfaces.go - UserInterface definition

User Implementation

Structure

type userImplementation struct {
    dataobject.DataObject
}

func NewUserFromExistingData(data map[string]string) UserInterface

Getter Methods

All properties have corresponding getter methods following the pattern GetPropertyName().

Setter Methods

All properties have corresponding setter methods following the pattern SetPropertyName(value) that return UserInterface for method chaining.

Usage Example

// Create new user
user := userstore.NewUser().
    SetStatus(userstore.USER_STATUS_ACTIVE).
    SetFirstName("John").
    SetLastName("Doe").
    SetEmail("test@test.com")

// Set password with hashing
err := user.SetPasswordAndHash("securePassword123")

// Set metadata
err = user.SetMeta("customField", "customValue")

// Check status
if user.IsActive() {
    // User is active
}

// Check role
if user.IsAdministrator() {
    // User is administrator
}
