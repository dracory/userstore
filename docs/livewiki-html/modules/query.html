Query Module

Query builder implementation

Overview

The Query module provides a fluent query builder for constructing complex user queries. It implements the UserQueryInterface and supports filtering, pagination, sorting, and various query options.

Key Files

  • query_user.go - User query builder implementation
  • interfaces.go - UserQueryInterface definition

Query Implementation

Structure

type userQueryImplementation struct {
    properties map[string]any
}

Constructor

func NewUserQuery() UserQueryInterface

Filter Methods

Basic Filters

Method Description
SetID(id)Filter by user ID
SetIDIn(idIn)Filter by list of IDs
SetEmail(email)Filter by email
SetFirstName(firstName)Filter by first name
SetLastName(lastName)Filter by last name
SetStatus(status)Filter by status
SetStatusIn(statusIn)Filter by list of statuses

Pattern Matching Filters

Method Description
SetEmailLike(emailLike)Filter by email pattern (LIKE)
SetFirstNameLike(firstNameLike)Filter by first name pattern (LIKE)
SetLastNameLike(lastNameLike)Filter by last name pattern (LIKE)
SetMetaLike(metaLike)Filter by metadata pattern (LIKE)

Date Filters

Method Description
SetCreatedAtGte(createdAtGte)Filter by created date >=
SetCreatedAtLte(createdAtLte)Filter by created date <=

Pagination Methods

Method Description
SetLimit(limit)Set maximum number of results
SetOffset(offset)Set result offset for pagination

Sorting Methods

Method Description
SetOrderBy(orderBy)Set column to order by
SetSortDirection(sortDirection)Set sort direction (ASC/DESC)

Option Methods

Method Description
SetColumns(columns)Select specific columns
SetCountOnly(countOnly)Return count only (no rows)
SetSoftDeletedIncluded(softDeletedIncluded)Include soft-deleted records

Helper Methods

Method Description
Validate()Validates query parameters
Has*()Checks if a property is set

Usage Examples

Basic Query

query := userstore.NewUserQuery().
    SetStatus(userstore.USER_STATUS_ACTIVE)

users, err := userStore.UserList(context.Background(), query)

Query with Pagination

query := userstore.NewUserQuery().
    SetStatus(userstore.USER_STATUS_ACTIVE).
    SetLimit(10).
    SetOffset(0)

users, err := userStore.UserList(context.Background(), query)

Query with Sorting

query := userstore.NewUserQuery().
    SetOrderBy("created_at").
    SetSortDirection("DESC")

users, err := userStore.UserList(context.Background(), query)

Query with Pattern Matching

query := userstore.NewUserQuery().
    SetEmailLike("%@example.com").
    SetFirstNameLike("John%")

users, err := userStore.UserList(context.Background(), query)

Query with Multiple Filters

query := userstore.NewUserQuery().
    SetStatus(userstore.USER_STATUS_ACTIVE).
    SetStatusIn([]string{
        userstore.USER_STATUS_ACTIVE,
        userstore.USER_STATUS_INACTIVE,
    }).
    SetCreatedAtGte("2024-01-01").
    SetLimit(10).
    SetOrderBy("created_at").
    SetSortDirection("DESC")

users, err := userStore.UserList(context.Background(), query)

Query Including Soft Deleted

query := userstore.NewUserQuery().
    SetSoftDeletedIncluded(true)

users, err := userStore.UserList(context.Background(), query)

Count Query

query := userstore.NewUserQuery().
    SetStatus(userstore.USER_STATUS_ACTIVE).
    SetCountOnly(true)

count, err := userStore.UserCount(context.Background(), query)

Validation

The query builder includes validation to ensure query parameters are correct:

err := query.Validate()
if err != nil {
    return err
}

Validation Rules

  • String fields cannot be empty if set
  • Arrays cannot be empty if set
  • Limit must be greater than 0 if set
  • Offset must be >= 0 if set

Design Pattern

The query builder uses the builder pattern with method chaining:

  • All setter methods return UserQueryInterface
  • Enables fluent, readable query construction
  • Methods can be chained in any order
