Store Module

Store implementation and database operations

Overview

The Store module is responsible for all database operations including user CRUD operations, migrations, and database connection management. It implements the StoreInterface and provides a unified API for database interactions.

Key Files

  • store_implementation.go - Core store implementation
  • store_new.go - Store constructor and configuration
  • store_user.go - User-specific database operations
  • sqls.go - SQL generation for table operations

Store Implementation

Structure

type storeImplementation struct {
    userTableName      string
    db                 *sql.DB
    dbDriverName       string
    automigrateEnabled bool
    debugEnabled       bool
}

Constructor

func NewStore(opts NewStoreOptions) (StoreInterface, error)

Configuration Options

Option Type Description
UserTableNamestringName of the user table
DB*sql.DBDatabase connection
DbDriverNamestringDatabase driver name
AutomigrateEnabledboolAuto-migrate on init
DebugEnabledboolEnable debug logging

Database Operations

Migration Methods

Method Description
MigrateUpCreates the user table
MigrateDownDrops the user table

User CRUD Methods

Method Description
UserCreateCreates a new user
UserUpdateUpdates an existing user
UserDeleteHard deletes a user
UserSoftDeleteSoft deletes a user
UserFindByIDFinds a user by ID
UserFindByEmailFinds a user by email
UserListLists users matching query
UserCountCounts users matching query

SQL Generation

The store uses the SQL builder pattern to generate database-agnostic SQL statements.

Table Creation

func (st *storeImplementation) sqlUserTableCreate() (string, error)

Generates CREATE TABLE SQL with all required columns and proper types for the specified database driver.

Table Drop

func (st *storeImplementation) sqlUserTableDrop() (string, error)

Generates DROP TABLE SQL for the specified database driver.

Transaction Support

Migration methods support optional transaction parameter for atomic operations:

func (store *storeImplementation) MigrateUp(ctx context.Context, tx ...*sql.Tx) error

Usage Example

// Initialize store
userStore, err := userstore.NewStore(userstore.NewStoreOptions{
    DB:                 databaseInstance,
    UserTableName:      "user",
    AutomigrateEnabled: true,
    DebugEnabled:       false,
})

// Create user
user := userstore.NewUser().
    SetStatus(userstore.USER_STATUS_ACTIVE).
    SetFirstName("John").
    SetLastName("Doe").
    SetEmail("test@test.com")

err = userStore.UserCreate(context.Background(), user)

// Find user
user, err = userStore.UserFindByID(context.Background(), userID)

// Update user
user.SetFirstName("Jane")
err = userStore.UserUpdate(context.Background(), user)
