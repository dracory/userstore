Role Module

Role entity implementation

Overview

The Role module implements the role entity with all properties, methods, and business logic. It extends the dataobject.DataObject base class and implements the RoleInterface.

Note: Role functionality is currently commented out in the StoreInterface but the implementation is available for future use.

Key Files

  • role_implementation.go - Role entity implementation
  • interfaces.go - RoleInterface definition

Getter Methods

All properties have corresponding getter methods following the pattern GetPropertyName().

Setter Methods

All properties have corresponding setter methods following the pattern SetPropertyName(value) that return RoleInterface for method chaining.

Usage Example

// Create new role
role := userstore.NewRole().
    SetStatus(userstore.ROLE_STATUS_ACTIVE).
    SetName("Administrator").
    SetHandle("admin")

// Set metadata
err := role.SetMeta("permission_level", "high")

// Check status
if role.IsActive() {
    // Role is active
}
