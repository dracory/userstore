API Reference

Complete API documentation for UserStore interfaces and methods

Store Interface

The StoreInterface defines the contract for database operations.

Methods

Method Signature Description
GetUserTableName () string Returns the user table name
SetUserTableName (tableName string) Sets the user table name
MigrateUp (ctx context.Context, tx ...*sql.Tx) error Creates the user table
MigrateDown (ctx context.Context, tx ...*sql.Tx) error Drops the user table
EnableDebug (debug bool) Enables debug logging
GetDB () *sql.DB Returns the database instance
UserCreate (ctx context.Context, user UserInterface) error Creates a new user
UserCount (ctx context.Context, options UserQueryInterface) (int64, error) Counts users matching query
UserDelete (ctx context.Context, user UserInterface) error Hard deletes a user
UserDeleteByID (ctx context.Context, id string) error Hard deletes a user by ID
UserFindByEmail (ctx context.Context, email string) (UserInterface, error) Finds a user by email
UserFindByID (ctx context.Context, userID string) (UserInterface, error) Finds a user by ID
UserList (ctx context.Context, query UserQueryInterface) ([]UserInterface, error) Lists users matching query
UserSoftDelete (ctx context.Context, user UserInterface) error Soft deletes a user
UserSoftDeleteByID (ctx context.Context, id string) error Soft deletes a user by ID
UserUpdate (ctx context.Context, user UserInterface) error Updates a user

User Interface

The UserInterface defines the user entity contract.

Method Signature Description
IsActive () bool Returns true if user status is active
IsInactive () bool Returns true if user status is inactive
IsSoftDeleted () bool Returns true if user is soft deleted
IsUnverified () bool Returns true if user status is unverified
IsAdministrator () bool Returns true if user role is administrator
IsManager () bool Returns true if user role is manager
IsSuperuser () bool Returns true if user role is superuser
IsRegistrationCompleted () bool Returns true if first and last name are set
