Overview

UserStore is a robust user management package for Go applications

What is UserStore?

UserStore is a comprehensive Go library designed to simplify user and role management in applications. It provides a clean, fluent API for managing users with support for multiple database backends, security features, and flexible querying capabilities.

Key Features

Multi-Database Support

Supports SQLite, MySQL, and PostgreSQL out of the box with a unified API.

Security

Built-in password hashing with bcrypt and secure authentication methods.

Fluent API

Method chaining for intuitive and readable code patterns.

Query Builder

Powerful query builder for complex user searches and filtering.

Soft Delete

Soft delete support to preserve data while marking records as deleted.

Metadata Storage

Flexible metadata storage for custom fields and application-specific data.

Core Concepts

Users

Users are the primary entity in UserStore. Each user has:

  • Unique ID (auto-generated short ID)
  • Email address
  • Name fields (first, middle, last)
  • Password (hashed with bcrypt)
  • Role assignment
  • Status (active, inactive, unverified, deleted)
  • Metadata for custom fields
  • Timestamps (created, updated, soft deleted)

Roles

Roles define user permissions and access levels:

  • Superuser - Highest privilege level
  • Administrator - Administrative access
  • Manager - Management access
  • User - Standard user access

Status System

Users can have the following statuses:

  • Active - Fully active user
  • Inactive - Temporarily disabled
  • Unverified - Initial state, requires verification
  • Deleted - Soft deleted

API Convention

UserStore follows a consistent naming convention:

  • Getters: GetID(), GetName(), GetEmail(), GetStatus(), etc.
  • Setters: SetID(), SetName(), SetEmail(), SetStatus(), etc.

Database Support

UserStore supports the following databases:

Database Driver Status
SQLite modernc.org/sqlite Supported
MySQL go-sql-driver/mysql Supported
PostgreSQL lib/pq Supported

Dependencies

UserStore relies on several high-quality Go libraries:

  • github.com/dracory/dataobject - Data object management
  • github.com/dracory/sb - SQL builder
  • github.com/dracory/str - String utilities (bcrypt hashing)
  • github.com/dromara/carbon/v2 - Date/time handling
  • github.com/doug-martin/goqu/v9 - Query builder
