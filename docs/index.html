UserStore Documentation

A robust user management package for Go with support for SQLite, MySQL, and PostgreSQL

Key Features

User, Role, and Group Management. Complete CRUD for users, roles, and groups, plus user-to-role and user-to-group assignment tables with find-or-create helpers.

Fluent API. Entities and query builders use consistent Get/Set method chaining throughout.

Built-in Essentials. Password hashing and verification, soft deletes, meta (key-value) storage for custom fields, and per-entity query builders for complex searches.
