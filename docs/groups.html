Groups

Groups require GroupsEnabled: true in the store options, along with GroupTableName and UserGroupTableName. Use a name like "groups" for the table — "group" is a reserved SQL keyword.

Creating a Group

group := userstore.NewGroup().
    SetName("Staff").
    SetHandle("staff").
    SetStatus(userstore.GROUP_STATUS_ACTIVE)

err := userStore.GroupCreate(context.Background(), group)

Group statuses: GROUP_STATUS_ACTIVE, GROUP_STATUS_INACTIVE, GROUP_STATUS_DELETED. Status helpers: IsActive(), IsInactive(), IsSoftDeleted().

Finding Groups

// By ID or handle
group, err := userStore.GroupFindByID(ctx, groupID)
group, err := userStore.GroupFindByHandle(ctx, "staff")

// Find by handle or create with the given status
group, err := userStore.GroupFindByHandleOrCreate(ctx, "staff", userstore.GROUP_STATUS_ACTIVE)

// List with a query
groups, err := userStore.GroupList(ctx, userstore.NewGroupQuery().
    SetStatus(userstore.GROUP_STATUS_ACTIVE).
    SetLimit(10))

Adding Users to Groups

Memberships are stored in the user-group table via the UserGroupInterface entity:

userGroup := userstore.NewUserGroup().
    SetUserID(user.GetID()).
    SetGroupID(group.GetID())

err := userStore.UserGroupCreate(ctx, userGroup)

// Or find-or-create the membership
userGroup, err := userStore.UserGroupFindByUserIDAndGroupIDOrCreate(
    ctx, user.GetID(), group.GetID())

Checking Membership

// List a user's groups
groups, err := userStore.UserGroups(ctx, user.GetID())

// Check if a user belongs to one or more groups (all must match)
isMember, err := userStore.UserHasGroups(ctx, user.GetID(), []string{group.GetID()})

Updating and Deleting

group.SetName("Team")
err := userStore.GroupUpdate(ctx, group)

// Soft delete
err := userStore.GroupSoftDelete(ctx, group)
err := userStore.GroupSoftDeleteByID(ctx, groupID)

// Hard delete
err := userStore.GroupDelete(ctx, group)
err := userStore.GroupDeleteByID(ctx, groupID)

// Remove a membership
err := userStore.UserGroupDelete(ctx, userGroup)
err := userStore.UserGroupSoftDelete(ctx, userGroup)

Meta Fields

Groups support key-value meta fields, same as users: SetMeta, GetMeta, GetMetas, SetMetas.
