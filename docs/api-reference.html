API Reference

All store methods live on StoreInterface and take context.Context as the first argument.

Base Store

MethodDescription
GetUserTableName() / SetUserTableName(name)User table name.
GetRoleTableName() / SetRoleTableName(name)Role table name.
GetUserRoleTableName() / SetUserRoleTableName(name)User-role table name.
GetGroupTableName() / SetGroupTableName(name)Group table name.
GetUserGroupTableName() / SetUserGroupTableName(name)User-group table name.
MigrateUp(ctx, tx...)Create tables. Optional *sql.Tx.
MigrateDown(ctx, tx...)Drop tables. Optional *sql.Tx.
EnableDebug(bool)Toggle debug mode.
GetDB()Returns the underlying *sql.DB.

Entities

All entities implement Data(), DataChanged(), MarkAsNotDirty(), and ToMap(), plus Get/Set accessors for their columns and carbon-based datetime getters (GetCreatedAtCarbon, GetUpdatedAtCarbon, GetSoftDeletedAtCarbon).

  • UserInterface — NewUser(), NewUserFromExistingData(data)
  • RoleInterface — NewRole(), NewRoleFromExistingData(data)
  • GroupInterface — NewGroup(), NewGroupFromExistingData(data)
  • UserRoleInterface — NewUserRole(), NewUserRoleFromExistingData(data)
  • UserGroupInterface — NewUserGroup(), NewUserGroupFromExistingData(data)
