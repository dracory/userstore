Roles

Roles require RolesEnabled: true in the store options, along with RoleTableName and UserRoleTableName.

Creating a Role

role := userstore.NewRole().
    SetName("Administrator").
    SetHandle("admin").
    SetStatus(userstore.ROLE_STATUS_ACTIVE)

err := userStore.RoleCreate(context.Background(), role)

Role statuses: ROLE_STATUS_ACTIVE, ROLE_STATUS_INACTIVE, ROLE_STATUS_DELETED. Status helpers: IsActive(), IsInactive(), IsSoftDeleted().

Finding Roles

// By ID or handle
role, err := userStore.RoleFindByID(ctx, roleID)
role, err := userStore.RoleFindByHandle(ctx, "admin")

// Find by handle or create with the given status
role, err := userStore.RoleFindByHandleOrCreate(ctx, "admin", userstore.ROLE_STATUS_ACTIVE)

// List with a query
roles, err := userStore.RoleList(ctx, userstore.NewRoleQuery().
    SetStatus(userstore.ROLE_STATUS_ACTIVE).
    SetLimit(10))

Assigning Roles to Users

Assignments are stored in the user-role table via the UserRoleInterface entity:

userRole := userstore.NewUserRole().
    SetUserID(user.GetID()).
    SetRoleID(role.GetID())

err := userStore.UserRoleCreate(ctx, userRole)

// Or find-or-create the assignment
userRole, err := userStore.UserRoleFindByUserIDAndRoleIDOrCreate(
    ctx, user.GetID(), role.GetID())

Checking Membership

// List a user's roles
roles, err := userStore.UserRoles(ctx, user.GetID())

// Check if a user has one or more roles (all must match)
hasRoles, err := userStore.UserHasRoles(ctx, user.GetID(), []string{role.GetID()})

Updating and Deleting

role.SetName("Super Admin")
err := userStore.RoleUpdate(ctx, role)

// Soft delete
err := userStore.RoleSoftDelete(ctx, role)
err := userStore.RoleSoftDeleteByID(ctx, roleID)

// Hard delete
err := userStore.RoleDelete(ctx, role)
err := userStore.RoleDeleteByID(ctx, roleID)

// Remove an assignment
err := userStore.UserRoleDelete(ctx, userRole)
err := userStore.UserRoleSoftDelete(ctx, userRole)

Meta Fields

Roles support key-value meta fields, same as users: SetMeta, GetMeta, GetMetas, SetMetas.
