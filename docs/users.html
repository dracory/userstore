Users

The UserInterface entity represents a user account. Create one with NewUser() or hydrate one from stored data with NewUserFromExistingData(data).

Creating a User

user := userstore.NewUser().
    SetStatus(userstore.USER_STATUS_ACTIVE).
    SetFirstName("John").
    SetLastName("Doe").
    SetEmail("test@test.com")

err := userStore.UserCreate(context.Background(), user)

User Statuses

  • USER_STATUS_ACTIVE — active account
  • USER_STATUS_INACTIVE — inactive account
  • USER_STATUS_UNVERIFIED — registered but not verified
  • USER_STATUS_DELETED — deleted status

Status helpers: IsActive(), IsInactive(), IsUnverified(), IsSoftDeleted(), IsRegistrationCompleted().

Passwords

Passwords are stored hashed. Use SetPasswordAndHash to hash a plain-text password, and PasswordCompare to verify:

err := user.SetPasswordAndHash("secret-password")

ok := user.PasswordCompare("secret-password")

Finding Users

// By ID
user, err := userStore.UserFindByID(ctx, userID)

// By email
user, err := userStore.UserFindByEmail(ctx, "test@test.com")

// Find by email or create with the given status
user, err := userStore.UserFindByEmailOrCreate(ctx, "test@test.com", userstore.USER_STATUS_ACTIVE)

// List with a query
users, err := userStore.UserList(ctx, userstore.NewUserQuery().
    SetStatus(userstore.USER_STATUS_ACTIVE).
    SetLimit(10))

Updating a User

user.SetFirstName("Jane").SetEmail("jane@example.com")

err := userStore.UserUpdate(ctx, user)

Deleting a User

// Soft delete (sets soft_deleted_at)
err := userStore.UserSoftDelete(ctx, user)
err := userStore.UserSoftDeleteByID(ctx, userID)

// Hard delete
err := userStore.UserDelete(ctx, user)
err := userStore.UserDeleteByID(ctx, userID)

Meta Fields

Users support arbitrary key-value meta fields stored in a single column:

err := user.SetMeta("theme", "dark")
value := user.GetMeta("theme")

metas, err := user.GetMetas()
err = user.SetMetas(map[string]string{"theme": "dark"})   // overwrite all
err = user.UpsertMetas(map[string]string{"lang": "en"})   // merge

Profile Fields

In addition to name and email, the user entity includes BusinessName, Country, MiddleNames, Phone, Timezone, ProfileImageUrl, Memo, and a legacy single Role column. ProfileImageOrDefaultUrl() returns the profile image or a default avatar URL.

Role Helpers

The user entity exposes convenience checks against its role column: IsAdministrator(), IsManager(), IsSuperuser(). Constants: USER_ROLE_SUPERUSER, USER_ROLE_ADMINISTRATOR, USER_ROLE_MANAGER, USER_ROLE_USER.
