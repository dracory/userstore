Query Builders

Every entity has a dedicated query builder used with the store's List and Count methods. All setters return the query for chaining.

Common Options

All query builders share these setters:

SetterDescription
SetID(id)Filter by exact ID.
SetIDIn(ids)Filter by a set of IDs.
SetColumns(columns)Select specific columns.
SetCountOnly(bool)Used with Count methods.
SetLimit(n) / SetOffset(n)Pagination.
SetOrderBy(col) / SetSortDirection(dir)Sorting; use SORT_ORDER_ASC / SORT_ORDER_DESC.
SetSoftDeletedIncluded(bool)Include soft-deleted records (excluded by default).

UserQuery

users, err := userStore.UserList(ctx, userstore.NewUserQuery().
    SetStatus(userstore.USER_STATUS_ACTIVE).
    SetStatusIn([]string{userstore.USER_STATUS_ACTIVE, userstore.USER_STATUS_UNVERIFIED}).
    SetEmail("test@test.com").
    SetEmailLike("@example.com").
    SetFirstNameLike("Jo%").
    SetLastNameLike("D%").
    SetMetaLike("theme").
    SetCreatedAtGte("2025-01-01 00:00:00").
    SetCreatedAtLte("2025-12-31 23:59:59").
    SetOrderBy(userstore.COLUMN_CREATED_AT).
    SetSortDirection(userstore.SORT_ORDER_DESC).
    SetLimit(10).
    SetOffset(0))

count, err := userStore.UserCount(ctx, userstore.NewUserQuery().
    SetStatus(userstore.USER_STATUS_ACTIVE))

RoleQuery

roles, err := userStore.RoleList(ctx, userstore.NewRoleQuery().
    SetStatus(userstore.ROLE_STATUS_ACTIVE).
    SetHandle("admin").
    SetTitleLike("%admin%").
    SetParentID(parentID).
    SetOrderBy(userstore.COLUMN_NAME).
    SetSortDirection(userstore.SORT_ORDER_ASC).
    SetLimit(10))

GroupQuery

groups, err := userStore.GroupList(ctx, userstore.NewGroupQuery().
    SetStatus(userstore.GROUP_STATUS_ACTIVE).
    SetHandle("staff").
    SetTitleLike("%staff%").
    SetOrderBy(userstore.COLUMN_NAME).
    SetLimit(10))

UserRoleQuery

userRoles, err := userStore.UserRoleList(ctx, userstore.NewUserRoleQuery().
    SetUserID(userID).
    SetUserIDIn([]string{userID1, userID2}).
    SetRoleID(roleID).
    SetRoleIDIn([]string{roleID1, roleID2}).
    SetLimit(100))

UserGroupQuery

userGroups, err := userStore.UserGroupList(ctx, userstore.NewUserGroupQuery().
    SetUserID(userID).
    SetUserIDIn([]string{userID1, userID2}).
    SetGroupID(groupID).
    SetGroupIDIn([]string{groupID1, groupID2}).
    SetLimit(100))

Soft-Deleted Records

Soft-deleted records are excluded from list and count results by default. Pass SetSoftDeletedIncluded(true) to include them:

all, err := userStore.UserList(ctx, userstore.NewUserQuery().
    SetSoftDeletedIncluded(true))
